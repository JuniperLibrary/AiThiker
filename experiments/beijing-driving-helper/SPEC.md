# 北京外埠车出行合规引擎 —— 需求规格（题目）

**版本:** v1.0（题目重写）
**日期:** 2026-11-03
**状态:** 待评审
**前置文档:** `README.md`（v0.4 现状）、本文件为新题目，后续实现以本文件为准

---

## 0. 一句话题目

建立一个**法源驱动、可验证、可追溯**的北京外埠号牌机动车通行合规判断引擎：任何一条结论都能回溯到具体法条/通告原文、生效日期与数据版本，并能被第三方独立复核。

---

## 1. 背景与现状差距

现有 v0.4 原型已具备：区域/时段/证件三要素判断、节假日日历、路线体检、边界降级、进京证账本、纯逻辑单元测试。

但按本领域专家标准，存在以下**结构性差距**（本题目要解决的正是这些）：

| 差距 | 现状 | 专家标准 |
|---|---|---|
| 法源 | 概括性表述，无条款号 | 每条规则钉死到文件+条款+生效日期 |
| 构成要件 | 压缩成一句话 | 主体/时间/空间/行为/豁免逐项拆解 |
| 边界语义 | 中心线多边形 | “五环含/六环不含”的方向差异 + 缓冲区 |
| 规则分层 | 只有面判定 | 面(区域) / 线(特殊路段) / 车道三层 |
| 时间轴 | 只存当前版本 | 可回答“某历史日期适用哪版规则” |
| 不确定度 | 一句“请核实” | 来源+版本+误差+具体核实动作 |
| 验证 | 自造坐标测试 | 真实案例黄金测试集 + 多源交叉 |
| 数据审计 | 无 | 每份数据带 source/version/fetched_at |

---

## 2. 目标

1. **法源可溯**：规则条目结构化，每条结论可展开查看原文引用与生效区间。
2. **构成要件完整**：主体、时间、空间、行为、豁免、例外路段全部显式建模，禁止隐含假设。
3. **空间语义正确**：边界方向差异（五环含/六环不含）用缓冲区表达，边界粒度显式声明。
4. **规则分层**：面判定之外，建立特殊路段线规则表（二环主路、长安街延长线等）。
5. **政策时间轴**：规则带生效/废止日期，支持历史日期查询。
6. **结论带不确定度**：来源、数据版本、误差范围、核实方法、最后核对日期。
7. **可验证**：黄金测试集来自公开真实案例；多源交叉；可复现。

---

## 3. 非目标（明确排除，写死不可扩展）

- ❌ 摄像头点位、抓拍设备分布、抓拍概率评估
- ❌ “无抓拍路段”推荐、绕行/规避执法的任何建议
- ❌ 遮挡号牌、识别抓拍方向等辅助手段
- ❌ 逐向导航（turn-by-turn）——导航交给导航 App
- ❌ 实时路况预测、拥堵预报

> 说明：限行标志牌属**公开道路设施**，可用于实地核验边界与规则；抓拍设备点位不属此类，不纳入本项目任何数据集。

## 4. 法源优先原则与规则条目模型

### 4.1 法源优先

任何规则进入引擎前，必须满足：

- 可回溯到**原始文件**（法规/通告/通知），非转述
- 记录：文件名、条款号、发布机关、发布日期、生效日期、废止日期（如有）
- 保留原文措辞，尤其是“（含）”“（不含）”“以内”“以内道路”等限定词
- 无法回溯的规则 → 标记为 `pending_verification`，**不参与结论输出**

### 4.2 规则条目 schema

```yaml
rule_id: string
source:
  file: string            # 文件全名
  article: string         # 条款号
  issuer: string          # 发布机关
  published: date
  effective_from: date
  effective_to: date|null
  url: string             # 原文链接
  verified_at: date       # 最后核对日期
elements:
  subject: string         # 主体要件: 外埠号牌小客车 / 豁免车型清单
  time: string            # 时间要件: 工作日 7:00-9:00, 17:00-20:00
  space: string           # 空间要件: 五环路(含)以内道路
  action: string          # 行为要件: 在道路上行驶
  exemptions: [string]    # 豁免: 公交/出租/警车/救护/环卫...
  exceptions: [string]    # 例外路段: 二环主路全天禁行...
penalty:
  basis: string           # 处罚依据(法条)
  detail: string          # 罚款/记分, 必须查原文, 禁止凭记忆填写
  verified_at: date
confidence: high|medium|low
```

### 4.3 规则分层

| 层 | 载体 | 覆盖 |
|---|---|---|
| L1 面 | 多边形 + 缓冲区 | 五环内 / 六环内 / 通州全域 |
| L2 线 | 道路线（OSM way / 官方道路分级） | 二环主路、长安街延长线、机场高速进京段 |
| L3 车道 | 车道属性 | 公交专用道、应急车道 |

v0.4 只有 L1。本题目要求至少交付 L1+L2，L3 标记为后续。

| 类别 | 原始素材 | 来源 | 用途 |

| 历史版本 | 通告旧版页面 | Wayback Machine CDX API | 政策时间轴 |
| 案例 | 处罚决定、复议决定、12345 答复 | 裁判文书网 / 首都之窗 | 黄金测试集 |

## 6. 数据治理

### 6.1 边界语义（关键）

- 政策表述：“五环路**（含）**以内” vs “六环路**（不含）**以内”
- 中心线多边形无法表达方向差异 → 必须用**缓冲区**修正：
  - 五环：向外扩半个路幅（含五环主路本身）
  - 六环：向内缩半个路幅（不含六环本身）
- 缓冲距离需由道路分级数据推导，标注推导依据
- 每次边界判断输出：数据源、relation ID、抓取时间、误差估计

### 6.2 坐标系

- 基准：WGS-84（所有判断数据）
- GCJ-02 仅用于高德底图显示，显示/交互自动转换（v0.4 已实现，保留测试）

### 6.3 数据审计

每份数据必须带：
```
source: string
version: string        # 如 OSM relation 295982
fetched_at: datetime
license: string        # ODbL 等
```

### 6.4 时效

- 规则：`effective_from` / `effective_to`
- 数据：`fetched_at`
- 结论：`last_verified_at`
- 节假日日历：年度版本，未内置年份显式降级并提示

## 7. 判断模型与输出规范

### 7.1 输入

- 目的地/路线（WGS-84）
- 计划出发时间
- 车辆属性（号牌类型、能源类型、是否豁免车型）——**新增**
- 进京证记录（账本）

### 7.2 输出（每条结论必须包含）

```
判定结果: 可通行 / 需办证 / 禁止通行 / 需核实
法源引用: 文件 + 条款 + 生效区间 + 原文链接
数据版本: 边界/日历/规则各自版本
不确定度: 粒度声明(面级近似) + 误差范围
核实动作: 具体到“看什么标志 / 问哪个电话 / 打开哪个 App 对照”
最后核对日期
```

### 7.3 车辆属性维度（v0.4 缺失）

需建豁免车型表，每条带法源：
- 新能源（纯电）外埠小客车是否豁免五环高峰 —— **已核实（2026-11-03）**：仅本市纯电动小客车豁免尾号限行；外省区市号牌新能源小客车进京需办证并遵守全部禁限行规定（北京交警官方问答 325753046）。高峰豁免车型见 2010 年第 18 号通告第三条、市政府通告第四条，已入 `exempt-vehicles` 规则
- 使馆车、警车、军车、消防、救护、环卫、公交、出租 —— **已核实（2026-11-03）**：市政府通告第四条原文已入 `exempt-vehicles`
- 黄牌车 / 大货车 / 危险品运输车（另属货车限行体系）—— 引擎不适用，已在 `subject-scope` 披露
- 网约车（外地牌在京运营的合规性）—— **仍待核**

## 8. 验证体系

### 8.1 黄金测试集

- 来源：公开真实案例（行政处罚、行政复议、12345 答复）
- 每案例记录：输入（时间/地点/车辆）、官方结论、法源
- `pytest` 回归，任何人可重跑

### 8.2 三角验证

同一结论必须至少两源一致：
1. 本引擎
2. 导航 App 限行提示（高德/百度）
3. 官方问答 / 12345 答复

### 8.3 多源交叉

- 边界：OSM vs 天地图 vs 自然资源部行政边界
- 节假日：国务院通知原文 vs timor.tech（校对用，非权威源）

### 8.4 专业审阅

- 行政法律师：法源、构成要件、处罚与救济
- 交通工程师：空间语义、道路分级、缓冲区

### 8.5 可复现

- 数据快照 + 版本锁定
- 代码 + 测试全公开
- 换机器重跑结果一致

### 8.6 实地抽样

- 边界点限行标志牌照片核验（公开设施）

## 9. 交付物与验收标准

| 交付物 | 验收标准 |
|---|---|
| 规则库（YAML/JSON） | 每条含 source + elements + verified_at，无 `pending_verification` 参与结论 |
| 边界数据 | 带缓冲区、relation ID、抓取时间、误差估计 |
| 特殊路段线规则表 | 至少覆盖二环主路、长安街延长线 |
| 政策时间轴 | 可查询任意历史日期适用规则 |
| 判断引擎 | 结论含 7.2 全部字段 |
| 黄金测试集 | ≥20 个真实案例，pytest 全绿 |
| 三角验证报告 | 抽样结论与导航 App/官方问答对照记录 |
| 法律意见 | 行政法律师对构成要件与处罚的书面意见 |
| README/SPEC | 与实现一致，变更可追溯 |
