# 北京外埠车出行合规助手

**项目状态:** v0.5(单文件 HTML,可直接双击使用)
**最后更新:** 2026-11-03
**政策版本:** 2026-11-03(现行限行通告生效期 2026-03-30 ~ 2027-03-28,以官方最新发布为准)

> 📐 **新题目以 [`SPEC.md`](SPEC.md) 为准(v1.0,2026-11-03):** 法源驱动、可验证、可追溯的合规判断引擎。
> v0.5 已完成迁移第 1–2 步:规则库(法源驱动)入库、补班日逻辑翻转、新增尾号限行。

## 一、想法来源

### 原始诉求(已拒绝的部分)

车主使用**北京外埠号牌**车辆,日常用车在**五环外**。最初想法是:设置一个终点,让系统规划一条**规避沿线摄像头**的路线,防止因违反外埠车限行政策被拍。

**为什么不做:** 该功能的核心目的是帮助车辆逃避交通执法监控,让按规定不能进入限行区域的车辆违规上路且不留记录。这属于协助规避执法,不能做。

### 转正后的想法(实际实现)

重新审视后,真实痛点不是"躲摄像头",而是"怕被罚"。合规路径在大多数场景下足够简单——问题的本质是一个**决策辅助**问题:

> 我打算 X 时间去 Y 地,作为外埠车,能不能开?要不要进京证?会不会被限行?

因此把想法改造为**外埠车出行合规判断工具**:

- 输入目的地 + 计划时间
- 判断目的地所在的限行区域(五环内 / 五环-六环间 / 六环外 / 通州全域)
- 判断计划时间是否处于工作日早晚高峰限行窗口
- 给出明确结论:可通行 / 禁止通行 / 需进京证 + 替代建议
- 附带一个**进京证账本**,记录一年内办证次数与有效期(每年次数有限,用完就没了)

## 二、政策依据(政策版 2026-11-03)

| 规则 | 内容 | 法源 |
|------|------|------|
| 进京证 | 外埠号牌车辆进入**六环路(不含)以内**道路及**通州全域**,须办理进京通行证(北京交警 APP / 交管12123) | 京交发〔2018〕102 号 第一条 |
| 高峰限行 | 工作日 **7:00-9:00**、**17:00-20:00**,外埠小客车禁止在**五环路(含)** 以内道路通行;罚 100 元记 1 分 | 市政府通告 第二条 + 2010 年第 18 号通告 |
| 尾号限行 | 工作日 **9:00-17:00**,外埠小客车在五环(含)以内按车牌尾号限行,与本市车同步轮换;字母尾号按 0 管理;罚 100 元不记分 | 市政府通告 第二、三条 |
| 周末/节假日 | 非工作日不受高峰与尾号限制(进入六环内仍须办证) | 市政府通告 |
| 调休补班 | **补班的周六日不限行**(通告括注"工作日…因调休上班的星期六、星期日除外") | 市政府通告 正文括注 |
| 证有效期 | 每次最长 7 天,到期须续办/重新办理 | 京交发〔2018〕102 号 第二条 |
| 年度次数 | 每辆车每年最多办理 12 次(界面中可调整上限,以官方为准) | 京交发〔2018〕102 号 第二条 |
| 新能源 | **外埠号牌新能源小客车不豁免**(仅本市纯电动小客车豁免尾号限行) | 北京交警官方问答 325753046 |
| 特殊道路 | 二环(含)以内全天禁行、大兴/顺义部分道路高峰限行——本工具无几何数据,**未逐点判断**,出行前用导航核实 | 北京交警专题(已披露为未覆盖) |
| 到期驶离 | 进京证到期前须驶出六环内及通州全域,否则可能被处罚 | 京交发〔2018〕102 号 第二条 |

## 三、功能清单

1. **目的地判断**
   - 地图点选 / 18 个预置地点 / 手动经纬度
   - 可选高德 Web 服务 Key 做地址搜索
2. **节假日自动识别**
   - 内置 2025、2026 年法定节假日与调休补班日
   - 自动区分工作日 / 周末 / 法定节假日 / 补班日
   - **补班日不限行**(依现行通告括注翻转 v0.4 逻辑)
   - 支持手动覆盖(自动 / 按节假日 / 按补班日)
3. **车辆信息(可选)**
   - 车牌尾号输入(持久化 `jjz_plate`),用于 9–17 时尾号限行判断
   - 英文字母尾号按 0 号管理;不填则该时段只披露不判断
4. **合规结论**
   - 区域 + 时段 + 尾号综合分析,输出可通行 / 需办证 / 禁止通行
   - 显示最早可通行时间与相对倒计时(如"约 30 分钟后")
   - 分别提示高峰限行、尾号限行、进京证、年度余量、特殊路段
   - **法源引用块**:结论附实际依据的规则(文件 + 条款 + 原文链接 + 核对日期)
   - **处罚披露**:违规/需办证结论附处罚金额、记分与依据
   - **车辆假设与未覆盖披露**:显式声明假设车型,未建模规则(二环、大兴/顺义)只披露不判断
5. **规则库面板**
   - 10 条规则的法源、条款、生效区间、置信度、核对状态
   - 标注每条规则"✓ 参与判断"或"⚠ 未覆盖,仅披露"
   - 引擎参数(高峰时段、轮换表、12 次/7 天)全部从规则库派生,不硬编码
6. **边界不确定提醒**
   - 目的地点距五环/六环/通州边界 < 2.5km 时提示"以导航实际线路为准"
   - 六环外但贴近边界时,结论降级为"请核实",避免把界内误判为界外
7. **进京证账本**
   - 记录办理日期与有效天数,自动推算到期日
   - 按**计划出行日**判断证件是否有效(不再只看今天)
   - 年度已用/剩余次数、进度条、低余量提醒
   - 记录重叠检测、续办 7 天、导出/导入 JSON 备份、清空
8. **常用地点收藏**
   - 收藏当前点并命名,一键复判;支持删除
9. **时间快捷操作**
   - 现在 / 明天 8:00 / 跳到下个可通行时段
10. **路线合规体检**
    - 设置起点/终点(地图选点、当前位置、手动坐标),按「计划时间」出发
    - 配置高德 Key 后获取真实驾车路线(折线 + 分段耗时);未配置或请求失败时按直线 28km/h 估算并明确标注
    - 沿路线每 30 秒采样,按**到达时刻**判断:高峰进入五环、尾号限行时段进入五环、进入六环内/通州时证件是否有效、跨天证件过期
    - 输出违规时间区间(如"08:12–08:47 在五环内,早高峰禁行"、"10:50–11:19 尾号限行")与整体结论
    - 自动求"最早可合法出发时间"(避开高峰与尾号窗口),一键改出发时间并重检
    - 结论附未覆盖规则披露;地图绘制路线折线与起终点标记,随底图坐标系切换自动纠偏
11. **地图与降级**
    - 高德瓦片 / OpenStreetMap 切换,五环/六环/通州图层开关
    - Leaflet 多 CDN 回退;全部失败时自动降级为手动输入,核心逻辑不依赖地图
12. **移动端适配**
    - 窄屏上下布局,面板可滚动,操作提示使用 Toast

## 四、使用方法

直接双击 `index.html` 用浏览器打开即可,无依赖、无需安装、无后端。

- 点地图任意位置选点,或点预置地点/收藏地点
- 计划时间默认为当前时间(向上取整到 5 分钟),可改为未来时间
- 进京证记录与收藏自动保存在浏览器 `localStorage`
- 可选:在[高德开放平台](https://console.amap.com/)免费申请「Web 服务」Key,开启地址搜索
- 建议通过本地 HTTP 服务打开(定位、部分浏览器安全策略更友好):
  ```bash
  python -m http.server 8123 --directory .
  # 打开 http://127.0.0.1:8123/index.html
  ```

### 运行测试

```bash
node test-logic.js
```

测试从 `index.html` 中抽取「纯逻辑区」执行,不需要安装依赖。

## 五、技术要点

- **纯单文件 HTML**:CSS + JS 内联;Leaflet 1.9.4 多 CDN 回退(jsdelivr → bootcdn → unpkg)
- **纯逻辑区**:日期、节假日、几何、合规判断与 DOM 解耦,可被 Node 直接抽取测试
- **本地日期运算**:所有日期比较使用 `YYYY-MM-DD` 本地日期,避免 `toISOString()` 在 UTC+8 下的跨日偏差
- **真实边界数据**:五环(OSM relation 295957)、六环(295982)、通州行政边界(2988902)取自 OpenStreetMap,经 RDP 抽稀(五环 94 点、六环 158 点、通州 100 点);数据 © OpenStreetMap contributors,ODbL 1.0
- **坐标系一致性**:边界/地点统一使用 WGS-84;高德瓦片为 GCJ-02,显示时自动转换、点击/拖动时转回 WGS-84,避免约 500m 的底图偏移影响边界判断
- **几何算法**:射线法判断点在多边形内;等距圆柱投影计算点到线段距离(km);2.5km 内触发边界提醒
- **无地图降级**:Leaflet 加载失败时保留完整判断逻辑,经纬度可手输
- **法源驱动规则库**:`RULES` 常量内嵌纯逻辑区,每条含 source(文件/条款/生效区间/原文链接/verified_at)、elements(构成要件)、penalty(处罚)、confidence、implemented/gap;引擎参数(高峰时段、尾号轮换表、12 次/7 天)全部由 `getRule()` 派生,禁止硬编码
- **数据持久化**:`jjz_records` / `jjz_limit` / `jjz_favs` / `jjz_day_override` / `jjz_plate` / `amap_key`
- **XSS 防护**:收藏名称等用户输入统一转义后再插入 HTML

### 已知限制

- 五环/六环边界取自 OSM 道路中心线,通州为行政边界,均经抽稀(通州约数百米容差);望京、亦庄等边缘区域可能与实际可通行道路有偏差,以导航和现场标志为准
- 边界数据为 2026-11 快照,道路改线或行政区划调整后需重新抓取更新
- 2027 年及以后节假日未内置,需手动指定日期类型或更新 `CN_CAL`
- 尾号轮换表覆盖至 2027-03-28,之后日期只披露"待核实",不参与判断
- 二环(含)以内全天禁行、大兴/顺义部分道路高峰限行、延庆部分道路——**无几何数据,未逐点判断**,已在结论中披露为未覆盖
- 地址搜索依赖高德 Key,且浏览器直连高德接口可能受 CORS/配额影响
- 直接以 `file://` 打开时,Chrome 可能限制定位权限,可用手动输入
- 只判断目的地所在区域 / 路线沿线,不判断沿途红绿灯、车速等实时因素;直线估算模式误差更大,仅供参考
- 高德路线 API 在浏览器直连时可能受 CORS / 配额影响,失败时自动退化为直线估算
- 路线耗时来自高德预估或固定 28km/h 估算,实际到达时刻可能有偏差,临近高峰边界请留余量
